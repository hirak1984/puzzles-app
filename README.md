# Puzzles (iPhone app)

Native SwiftUI port of [puzzles.hirakonline.com](https://puzzles.hirakonline.com) —
Hashi and Train Tracks, generated on the fly, no ads, no accounts. This is a
personal-use app: nothing here assumes App Store distribution.

Ported from the web app at commit `fd96e25` of
[hirak1984/puzzles](https://github.com/hirak1984/puzzles) (includes the
Hashi path-highlight/blocked-edge fix and the 12×16 hard level).

## Status

Built entirely from the command line on a machine with only the Xcode
**Command Line Tools** installed (no Xcode app, no iOS SDK, no simulator) —
so this has **never been compiled for iOS or run**. What was verified
instead:

- The three files with no UIKit/SwiftUI dependency — `RNG.swift`,
  `Hashi.swift`, `Tracks.swift` (the puzzle generators and solvers) — were
  extracted into a throwaway Swift package and actually built and run on
  macOS. All levels generated puzzles that are provably unique, whose
  stored solutions validate as solved, and (for Hashi) that generation is
  deterministic per seed. The Hashi crossing-bridge fix was specifically
  exercised (`validEdge` flips false once a crossing bridge is placed).
- Every `.swift` file passed `swiftc -parse` (syntax only — no type
  checking, since that needs the iOS SDK).
- `xcodegen generate` produces a project that opens without errors; the
  font files and asset catalog are confirmed present in the generated
  `project.pbxproj` and `Info.plist`.

None of the SwiftUI views, gestures, or Canvas drawing code have been
type-checked or rendered. **The first `⌘R` in Xcode is the real test.**
Likely trouble spots if something doesn't compile: the `GameScreen`
generic view in `Views/Components.swift`, and the `DisclosureGroup`
styling — both are the least battle-tested SwiftUI APIs used here.

## Open it

Requires Xcode 15+ (iOS 17 deployment target). The `.xcodeproj` is
generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from
`project.yml` — regenerate it after editing `project.yml` or adding/removing
files:

```
brew install xcodegen   # if you don't have it
xcodegen generate
open Puzzles.xcodeproj
```

To run on your own iPhone: plug it in, select it as the run destination,
and under the target's *Signing & Capabilities* pick your Apple ID as the
team (a free account works — the app just needs reinstalling every 7 days;
paid developer program removes that limit).

## Layout

```
project.yml              XcodeGen spec (edit this, not the .xcodeproj)
Puzzles/
  PuzzlesApp.swift        App entry, NavigationStack, theme toggle
  Models/
    RNG.swift             mulberry32 seeded RNG            ← rng.js
    Hashi.swift            model, solver, generator, status ← hashi.js
    Tracks.swift            model, solver, generator, status ← tracks.js
    HashiEngine.swift      ObservableObject: live game state + interaction
    TracksEngine.swift      ObservableObject: live game state + interaction
  Views/
    HomeView.swift          game list                       ← app.js renderHome()
    HashiGameScreen.swift    Hashi screen + rules text       ← app.js GAMES.hashi
    TracksGameScreen.swift    Tracks screen + rules text      ← app.js GAMES.tracks
    Components.swift        GameScreen shell, buttons, win/toast overlays
    HashiBoardView.swift     Canvas board + gestures          ← hashi-ui.js
    TracksBoardView.swift     Canvas board + gestures          ← tracks-ui.js
    GameIcons.swift          home-screen icons                ← app.js GAMES icons
  Support/
    Theme.swift              color tokens + fonts             ← styles.css
    Store.swift              UserDefaults persistence         ← common.js store
  Fonts/                   Inter + Source Serif 4 (OFL, from Google Fonts)
  Assets.xcassets/          app icon ("P" monogram) + accent color
```

Puzzle logic (`Models/Hashi.swift`, `Models/Tracks.swift`, `Models/RNG.swift`)
is a line-for-line port of the web app's generators and solvers, including
the same level configs (Hashi hard is 12×16 / ~48 islands; Tracks hard is
10×10). Seeds are **not** shared with the web app — the RNG algorithm
matches bit-for-bit, but the app consumes it independently, so the same
seed number produces a different puzzle on each platform. That's fine: the
app picks a fresh random seed per puzzle, same as the site.

## Persistence

UserDefaults stands in for the web app's `localStorage`: per-puzzle
progress (keyed by game/level/seed), solved-count/best-time stats per
level, the last-used difficulty per game, and the light/dark/system theme
choice.

## Fonts

`Fonts/Inter.ttf` and `Fonts/SourceSerif4.ttf` are the variable-font files
from [google/fonts](https://github.com/google/fonts) (SIL Open Font
License — see `Fonts/OFL-*.txt`), the same families the web app loads from
Google Fonts. They're registered via `UIAppFonts` in `Info.plist` and
referenced as `Font.custom("Inter", …)` / `Font.custom("Source Serif 4", …)`.
